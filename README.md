# Ziggo Besparingscheck

Mobiele web-app (PWA) voor deur-aan-deur sales: laat snel zien hoeveel een klant
bespaart bij overstap naar Ziggo/Vodafone. Geoptimaliseerd voor tablet/telefoon,
installeerbaar en offline bruikbaar.

## Gebruiken
Open de gehoste versie (GitHub Pages) in Chrome op je tablet en kies
**Menu → App installeren** om 'm op je startscherm te zetten.

## Inhoud
- `index.html` — de volledige app (HTML/CSS/JS in één bestand)
- `manifest.webmanifest` — PWA-manifest
- `sw.js` — service worker (offline)
- `icons/` — app-iconen
- `logo.svg` — Ziggo-wordmark (vector)
